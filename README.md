# TOPIK 읽기 연습

TOPIK Ⅱ 읽기(読解) 과거문제(제96회・제91회, 98문) + 쓰기(작문) 연습(8문)을 풀 수 있는 자기학습용 웹 앱입니다.

- 정답을 고르면 바로 정답 여부와 문법/독해 해설이 표시됩니다
- 그래프 문제는 실제 도넛/막대 그래프로 표시됩니다
- 한국어/日本語 표시 전환 가능
- 자주 틀리는 문법/문제를 확인할 수 있는 학습 기록 기능(브라우저 로컬 저장)

## 사용법

GitHub Pages로 배포된 페이지를 그대로 열어서 사용하면 됩니다. 별도의 설치나 빌드 과정이 필요 없습니다.

## 출처

과거문제 원본은 [trilingual.jp](https://trilingual.jp/topik/)에서 무료로 제공하는 공식 TOPIK 기출문제를 바탕으로 만들었습니다.
